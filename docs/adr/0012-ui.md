# 0012. UI

Estado: aceptada (2026-10-04)

## Decisión
- Web propia estilo workspace de Databricks (catálogo, editor SQL, notebooks, pipelines/jobs,
  ingesta, alertas, dashboards, ML, admin), servida por `duct serve` desde el mismo binario
  (`go:embed`), sin Node en producción.
- **Go + templ + Datastar** (SSE para lo live) + **templUI** + **Tailwind** (binario standalone).
- Islas JS solo donde es inevitable: CodeMirror 6, ECharts, xyflow, DuckDB-WASM opcional;
  empaquetadas con esbuild como librería Go. marimo y la UI de MLflow embebidos.

## Descartados
- Next.js/React/SQLRooms (peso), Svelte (JS de app), HTMX (Datastar cubre mejor lo live),
  Go→WASM (binarios grandes), Rust→WASM (tercer lenguaje).
