# Marca de Duct

Una "D" hecha de tubería: un tramo recto de acero (el núcleo) unido por bridas a un codo
naranja (el flujo). Infraestructura sin glamour, a la vista.

| Archivo | Uso |
|---|---|
| `logo.svg` / `logo-dark.svg` | Ícono vectorial (fondo claro / oscuro) |
| `icon.png` | Ícono 256×256 en PNG (lo usa Paseo como ícono del workspace; <32 KB) |
| `wordmark.svg` / `wordmark-dark.svg` | Logo con nombre (fondo claro / oscuro); texto en trazos |

Paleta:

| Color | Hex | Uso |
|---|---|---|
| Naranja seguridad | `#F26B1D` | codo, acentos |
| Acero | `#2B3440` | tramo recto, texto en fondo claro |
| Brida | `#161B22` | bridas en fondo claro |
| Perno / gris | `#8A96A3` | pernos, bridas en fondo oscuro |
| Hueso | `#E6EAEE` | texto y tramo en fondo oscuro |

Tipografía del nombre: JetBrains Mono Bold (convertida a trazos en el SVG).
